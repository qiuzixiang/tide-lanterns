# 潮汐灯塔 · 规则与产品契约

版本 1.0，2026-09-05。

## 选择

从现有合集选择「风暴灯塔网 / Net」。点击旋转接线模块、沿主灯塔点亮整条航路，与《星际漂流》的惯性移动不同。目标是通过有层次的关卡、群岛修复与每日题维持新鲜感；不承诺无限不厌倦，也不把章节序号或旋转数伪装成经测量的难度。

## 规则真值

- 使用矩形、不回绕的棋盘。每格是 N=1/E=2/S=4/W=8 的非空端口位掩码。
- 合法操作是原位旋转，不能改变模块形状或移动模块。允许顺时针与逆时针操作。
- 仅双方端口相对时相连。主灯塔所在格始终通电，其他格沿真实相连的边传播通电。
- 完成必须同时满足：没有向外越界端口；没有未配对端口；所有格连接到主灯塔；网络没有环。
- 锁定是玩家笔记，可解除；辅助高亮、声音、动画、计数、提示和成就不参与胜负判定。
- 无强制倒计时或失败惩罚。撤销、重做和重开可用。提示明确标注会展示一个方向，不冒充推导过程。
- 48 个战役关卡，6 章，每章 8 关；棋盘最大 6×6，320px 屏幕仍可提供至少 44px 格子。结构逐步引入边界、端点、转角、分支和全局连接。
- 每日与自由航行取自额外离线验证题库，明确为有限题库轮换；不宣传无限动态生成。日期采用设备本地日期。
- 唯一解必须由不读取预存解的独立求解器搜索到第二解上限 2，且搜索完整结束。超时或预算耗尽不能记为唯一。生成与验证在构建前执行，游戏启动不做搜索。

## 主题与交互

端口→海底光缆，格点→航标岛，根→主灯塔；通电用金色光和灯芯形状双重表达；未通电用灰蓝电缆和空灯环；笔记用锁图标。教程必须由真实 3×3 题面复算：元素、一次合法旋转、真实完成。

画面采用海图、暖纸、海绿与琥珀灯光，避免复用星际漂流视觉模板。六章群岛各有航海故事、收藏纪念物；奖励按唯一关卡首次通关与独立通关幂等计算，无惩罚性连续登录。

## 存储与发布

独立命名空间 `tide-lanterns:v1`；所有恢复数据校验题目 ID、形状、动作与胜利真值。完成记录使用关卡 ID 与验证完成记录稳定去重，不信任外部完成布尔值。禁止清空别的存档。

桌面网页与小红书共用同一源代码，构建为外置经典 ES2017 脚本、单 index.html 与本地资源。无网络、后台、剪贴板、外部跳转或桥接权限。手机预留平台导航与安全区；短窗口可滚动，弹层内部滚动，操作按钮可达。

用户明确授权独立开发及发布 GitHub、Vercel、小红书；具体平台协议如要求单独确认，在完成上传预览后处理。
