## 独立测试方法与覆盖

命令：

```sh
node --test tests/storage.test.mjs tests/runtime.test.mjs
```

`tests/storage.test.mjs` 直接导入生产规则、题库与存储模块。`tests/runtime.test.mjs` 使用现有 esbuild 将实际 `src/app.mjs` 及其真实 imports 在内存打包，再放入 Node VM 执行。仅在测试副本尾部追加状态访问入口；不修改或替换生产行为函数，不把测试入口写入发布产物。

最小 DOM 只模拟元素、事件、焦点和读写，不实现浏览器布局、绘制、触摸命中、CSS、CSP 或原生 WebView。计时器由测试控制。没有把模拟 DOM 当成真实浏览器。

存储 16 项覆盖：

- 独立初始保存对象与私有键；保存只读写 `tide-lanterns:v1`，不影响其他游戏键。
- 真实动作日志恢复旋转、锁定、游标和有效 redo 尾部；无效动作、锁定后非法旋转、损坏尾部、无效计数或未知关卡不能恢复。
- 伪造棋盘、完成布尔或 `status:'won'` 不能覆盖动作回放；真正完成的动作序列可恢复，完成后的非法旋转不被接受。
- 未完成或改变形状的 masks 不能伪造 claim；重复 claim 幂等，优先保留提示更少/转动更少的记录；自由题不计入战役进度。
- 提示数与 `clean` 矛盾时不能伪造独立修复徽记；损坏 JSON 与真实存储不可用分别处理。
- 缺失、抛错、写配额耗尽、序列化失败安全回退；每日局日期和各尺寸自由航行计数规范化。

运行时 15 项覆盖：

- Web 与小红书两版生产入口在移除 flat/flatMap/at/fromEntries/hasOwn/replaceAll/globalThis，以及缺少 matchMedia、音频、visualViewport、原生 dialog、指针捕获等可选能力时启动并可操作。
- 真实 DOM 绑定的点击、逆转、右键/键盘锁定、撤销、重做；新动作仅丢弃 redo 尾部，提示计数经撤销/重做/刷新保持。
- 提示说明不计次数，揭示后才计数；帮助转正一个锁定航标会记录真实解锁和旋转动作。
- 真实通关幂等保存、刷新恢复、旧延迟回调不能污染新关卡；其他弹层占用通关延迟的场景有独立回归。
- 自由航行取消不推进序号、各尺寸序列独立、恢复 6 阶局后通关仍续 6 阶；地图提供收藏和自由航行入口。
- 弹层 Escape/Tab 焦点环、可见游玩计时/pagehide 保存、减少动态效果，以及实际设置视图内完整 MIT/署名入口。

这些测试验证应用功能与数据边界，不提供反篡改安全保证：全部谜题与客户端数据在本机运行，用户可以自行修改代码；本产品没有服务端信任或竞赛排名承诺。

## 已发现并修复的问题

1. **手机/半屏核心入口不可达**：初版收藏只在隐藏的侧栏，自由模式只在半屏隐藏的 footer。实现已在所有尺寸可打开的地图弹层加入独立入口；生产事件流测试通过。实际布局仍待浏览器验证。
2. **伪造独立修复徽记**：初版 claim 恢复直接信任 `clean`。现根据 `hints === 0` 约束，提示局不能恢复成独立修复；有效完成记录保留，回归通过。
3. **损坏存档误报环境不可保存**：初版混淆 JSON 损坏和读取异常。现读取成功而 JSON 损坏会返回初始档且保持可用标志；写入成功恢复持久化状态。回归通过。
4. **自由局续关意外换难度**：初版刷新后 `freeSize` 固定为 5，恢复 4/6 阶局通关会进入 5 阶。现初始化/切关按实际局尺寸，通关续题直接使用该局尺寸；6 阶完整通关续题回归通过。

## 已修复并回归：通关延迟被其他弹层消耗

发现时位置：`src/app.mjs:124` 的 `finishRun` 与 `src/app.mjs:135` 的 `closeModal`。

最后一转完成后，`finishRun` 先持久化 claim，再等 720 ms 展示通关。在延迟结束前打开设置或图解，回调看到 `modalKind` 非空便直接退出；之后关闭设置，`closeModal` 不恢复待展示结果。完成记录仍存在，但本次通关反馈与下一关按钮丢失。

真实生产入口 VM 复现命令：

```sh
node --test --test-name-pattern='completion presentation survives' tests/runtime.test.mjs
```

初次结果：1 项失败，实际 `modalKind === ''`，预期关闭占用弹层后展示 `win`。实现现保留带 revision 的待展示结果，在其他弹层关闭后异步尝试展示；换关、撤销或新动作同时清理待展示结果并使旧 revision 失效。最终复跑该案例通过，同轮“旧延迟不能污染另一关”的回归也通过。
